# Дизайн-система hottell

Источник — дашборд v3 из репозитория [nuanu-ai/ai-hottell](https://github.com/nuanu-ai/ai-hottell),
файл `ui/static/index.html`, коммит `b4b6153` (HT-118). Принцип v3: _product shell — top bar, tabs,
dense panels on a 12-col grid; tables and charts carry the page._

Обычный CSS без Tailwind и CSS-in-JS. Имена токенов и классов взяты из v3, поэтому экран,
перенесённый из v3, сохраняет свои стили. Шрифты IBM Plex Sans и IBM Plex Mono ставятся
локально из `@fontsource/*` (`src/app/main.tsx`): страница не обращается к внешним доменам.
Углы квадратные (у `.tag` 2px), тени не используются.

## Темы

Две темы, тёмная и светлая; по умолчанию — как в системе (`prefers-color-scheme`).
Тёмные значения лежат в `:root`, светлые — в `:root[data-theme='light']`. Переключатель
в шапке — три кнопки: «Как в системе», «Тёмная», «Светлая»; выбор хранится в `ht-theme`
в localStorage (`system`, `dark` или `light`). Скрипт в `web/index.html` ставит
`data-theme` до первой отрисовки: явный выбор, иначе системную тему, а без `matchMedia` —
тёмную. `src/shared/lib/theme.ts` — его копия, и `theme.test.ts` сверяет их. Пока выбрано
«Как в системе», `followSystemTheme` переключает тему вслед за системой.

## Токены (`styles/tokens.css`)

| Токен                                  | Назначение                                                                                  |
| -------------------------------------- | ------------------------------------------------------------------------------------------- |
| `--bg`                                 | фон страницы                                                                                |
| `--surface`, `--surface-2`             | панели; вложенный фон (код, пустая полоса)                                                  |
| `--hover`                              | подсветка строки и кнопки при наведении                                                     |
| `--line`                               | рамки и разделители                                                                         |
| `--ink`, `--ink-2`, `--ink-3`          | основной, вторичный и приглушённый текст                                                    |
| `--accent`, `--accent-soft`            | действие и выбор; фон выбранного                                                            |
| `--accent-hover`                       | заливка основной кнопки при наведении: контраст с `--on-accent` не ниже 4.5:1 в обеих темах |
| `--on-accent`                          | текст на заливке акцентом и на `--accent-hover`: тёмный в тёмной теме, белый в светлой      |
| `--m1`…`--m4`                          | цвета серий графиков                                                                        |
| `--ok`, `--warn`, `--bad` и их `-soft` | смысловые цвета и их фоны                                                                   |
| `--f-body`, `--f-mono`                 | шрифты                                                                                      |

Отличия от v5.1 — осознанные: светлый `--ink-3` — `#626e7f` вместо `#737f90`, чтобы приглушённый
текст держал контраст 4.5:1 на `--bg`, `--surface` и `--surface-2`; текст на акценте — `--on-accent`
вместо `#fff`, потому что на светлом акценте тёмной темы белый текст не читается. Неиспользуемых
токенов нет: `tokens.test.ts` проверяет, что каждый токен где-то читается через `var()`.

## Заголовки внутри панели

Заголовок панели — `h2` в `.ph` (14px/600). Подпись раздела внутри панели — `h3`: правило
`.p h3` в `styles/panels.css` оформляет его как `.lbl` (500 11px mono, капс, `--ink-3`, без полей),
поэтому раздел остаётся заголовком для чтения с экрана и мельче заголовка панели. Заголовки `Empty`
и `Dialog` внутри панели это правило не трогает.

## Как добавить компонент

1. Стили — в файл своей группы в `styles/` (или новый файл, импортированный в `styles/index.css`).
2. Компонент — в `shared/ui`, экспорт в `index.ts`.
3. Секция на витрине `/design` (`src/app/design/sections/`, есть только в dev-сборке: `pnpm dev`).
4. Снимок разметки в `markup.test.tsx`.

## Ещё не перенесено из v3

Переедут вместе с экранами аналитики: строки проверок `.ck`, заданий `.task`, источников `.src`.
