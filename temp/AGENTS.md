# harness-telemetry

Личный проект телеметрии агентских harness — Claude Code и Codex.
Репозиторий: https://git.alva.dev/alva/harness-telemetry.

## Инструкции для агентов

Процесс задаёт пакет `team-skills`. Перед работой прочитать
`team-skills:agents-using-skills`, затем `team-skills:agents-developer`.
Репозиторные настройки находятся в [`.agents/team-profile.yaml`](.agents/team-profile.yaml).
Работа с задачами — через `team-skills:agents-taskmanager`.
Первичное проектирование продукта — через `team-skills:bootstrap`, доставка
принятого слайса — через `team-skills:slice-delivery`.

## Задачник

Itsaplan: проект **harness-telemetry**, ключ **HT**, project ID **8**,
команда **alva**, team ID **1**. MCP-сервер:
`https://tasks-api.alva.dev/mcp`, инструменты `mcp__itsaplan__*`.

- Перед созданием задачи искать существующую в `HT`.
- `HT-N` читать через `get_issue_by_number(projectKey="HT", sequenceNumber=N)`.
- Перед изменением задачи проверять, что её `projectId` равен **8**.
- Колонки и типы брать из свежего `get_project(projectKey="HT")`;
  колонку выбирать по `stateType`, а не по названию или ID другого проекта.
- После записи читать результат повторно. Не считать ошибку или потерянный
  ответ успехом и не повторять создание вслепую.
- Идентификатор `HT-N` указывать в имени рабочей ветки и сообщении коммита.

В установленном `team-skills` нет встроенного адаптера Itsaplan, поэтому
операции, состояния и возможности объявлены явно в профиле. Поля `output`
описывают JSON из текстового MCP-результата; при использовании
`structuredContent` тот же объект находится в `data`.

## Границы проекта

Исходная задача — настройка hottell и нативного OTel обоих агентов на Mac.
Реализация, архитектура и roadmap нового проекта пока не согласованы.
Секреты, токены, транскрипты и реальные payload событий не помещать в Git
или задачник и не выводить в чат.

Memory bank пока не создан. Спецификации и планы размещать по путям профиля;
полный memory bank создаётся через bootstrap после согласования назначения
и объёма продукта.

`main` — защищённая ветка по правилам проекта: не коммитить в неё напрямую.
Первичная публикация в Gitea разрешена владельцем 30.09.2026.
Порядок последующей интеграции ещё не согласован; до этого профиль
не объявляет `integration`.
