# Share-pack и командный вид

Что участник отдаёт в командный вид и как считается сравнение. Формат, передача и хранение — техническая часть.

## Правила

- Участие добровольное: share-pack собирает и отправляет сам участник.
- Выбор — по сессиям и по уровню. Невыбранное остаётся у участника.
- Принцип allowlist: уходит только перечисленное ниже; новое поле без записи в этот файл не уходит.
- Сырые реплики, ответы агента, выводы инструментов, пути, команды и содержимое настроек не уходят никогда.
- Командные показатели показываются при ≥ 3 участниках.

## Уровни

| Поле | `metrics` | `metrics_facets` | `excerpts` |
|---|---|---|---|
| Участник: имя в команде | да | да | да |
| Сессия: id в виде хэша, дата (день), агент, класс задачи, длительность, токены | да | да | да |
| Вердикт и `human_load_min` | да | да | да |
| Подтверждённые эпизоды: паттерн, severity, затраты | да | да | да |
| Использование skills: имя skill, число активаций | да | да | да |
| Настройки: вид, статус (свежий / устарел / не используется / противоречит), число элементов; для skill и MCP — имя | да | да | да |
| Предложения: паттерн, класс, «было — должно быть», статус, эффект | да | да | да |
| Фасеты: задача одной фразой, критерий готовности, где ушло время, кандидаты в автоматизацию | — | да | да |
| Цитаты, выбранные участником, после маскирования | — | — | да |

Никогда: тексты реплик и ответов целиком, выводы инструментов, аргументы вызовов, абсолютные пути, названия проектов клиентов, email, ключи и токены, содержимое AGENTS.md, CLAUDE.md и памяти.

## Сравнение с командой — после MVP

Практики и их определения — [metrics.md §9](metrics.md). Для каждой практики — значение участника и медиана команды за тот же период. Лучшие практики — верхняя четверть; пример показывается, только если его автор отдал уровень `excerpts`.

## Профиль skill

Для skill, который используют ≥ 2 участника: число активаций, классы задач, доля сессий с эпизодом D25, распределение вердиктов в сессиях с этим skill и в сессиях того же класса без него.
