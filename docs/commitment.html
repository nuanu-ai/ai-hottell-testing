Что деливерим к демо

Предлагаемый минимум MVP

Сборщик + датасет

Повторяемый сбор из выбранных сессий Codex, понятный формат записи и реальные примеры данных.

Анализ + рекомендации

Метрики и разбор затруднений с опорой на сессию. Для каждого вывода — конкретное предложение, что изменить.

Skill + пакет для хаба

Извлечение нужного контекста и предпросмотр общей копии. В командный контур попадает только выбранное человеком.

Критерий демо: пройти всю цепочку на реальной сессии.Запуск сбора → запись в датасете → метрики и обоснованный вывод → предложение улучшения → выбор пакета для хаба. Повторить процесс на другой сессии по той же инструкции.

Смотрим: время до результата, токены, повторные циклы и достижение цели. Недоступные метрики отмечаем явно; способ оценки качества результата ещё предстоит определить.
