## Приёмка

- Открывается «Что исправить» за 7 дней; тема — как в системе.
- В «Цикле» число «Сигналов» равно сумме эпизодов тем и строк «Трения» при той же выборке. При неполной выборке без `by_session` — «—» и «нет счёта по сессиям».
- «Сессии»: при 1440×900 на экране около 20 строк по 36px, «Задача» читается; в «Сигналах» один тег и «+N».
- Подписи «Ваши сессии», «Агент работал», «Расходы», строка полноты и заголовок «Сессии» считают одну выборку и называют запуски по расписанию и скрытые служебные.
- Склонения верные: «1 событие», «2 события», «5 событий».
- На ширине 390px у страницы нет горизонтальной прокрутки, таблицы прокручиваются внутри панелей.
- `prefers-reduced-motion` — без движения. Скрытая вкладка не опрашивает `/api/pulse` и `/api/dataset` (проверить во вкладке «Сеть»).
- «Глубокий разбор» (:8800) — тот же каркас без пульса, без регрессий.
- `go vet ./... && go test ./...` в `ui/`, `python3 -m unittest` в `ui/builder/` — зелёные.
