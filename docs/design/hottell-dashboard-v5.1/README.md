# Handoff: hottell dashboard v5.1 — «Живые данные»

## Overview
Итоговый интерфейс локального дашборда AI Hottell (`ui/`, порт :8801 «Живые данные»; :8800 «Глубокий разбор» — тот же каркас без пульса). Реализует `docs/specs/2026-10-01-ux.spec.md` с учётом `2026-10-01-hottell-coach.spec.md` и плана `2026-10-01-live-honest-dashboard.plan.md`.

Задача интерфейса: за минуту понять **что мешает работать с агентами, что с этим сделать и помогло ли сделанное**. Всё остальное — подробности по запросу.

## About the Design Files
Файлы в этом пакете — **дизайн-референс в HTML**: прототип, показывающий целевой вид и поведение, а не код для копирования. Задача — **воспроизвести дизайн в `ui/static/index.html`** (ванильный JS + CSS, без сборки и новых зависимостей, как требует спецификация), используя существующие классы `.kpi`, `.hero`, `.seg`, `.tag`, `.bar`, `.p`, `.ph`, `.fr`, `.ev`, `.cov` и токены из `:root`.

Как открыть прототип: запустить статический сервер в этой папке (`python3 -m http.server`) и открыть `Hottell Dashboard v5.dc.html`. Данные — реальный `local-data/ui-live/dataset.json` (сборка 01.10.2026 04:19 UTC) и 10 лент из `local-data/ui-live/sessions/`. `support.js` — среда исполнения прототипа, в продукт не переносится.

## Изменения v5.1
- «Сессии»: таблица с `table-layout:fixed` и шириной колонок, «Задача» читается; в «Сигналах» один тег и «+N», полный список в `title`; строка 36px.
- Счёт эпизодов не использует доказательства: они в данных обрезаны до 60. Если весь сигнал в выборке — `count`, иначе сумма `by_session` (план T3), а без неё — «—».
- Одна база на странице — сессии выборки (под «Без служебных» это ваши и запуски по расписанию). Подписи называют запуски по расписанию и скрытые служебные отдельно.
- Служебные сессии: добавлена проверка подсказок Codex («You are an expert at upholding safety and compliance standards for Codex ambient suggestions…»).
- Тема по умолчанию — системная (`prefers-color-scheme`).
- Склонения: «1 событие», «2 события», «5 событий».
- Подпись оси расходов в одну строку.

## Fidelity
**High-fidelity.** Цвета, шрифты, отступы, тексты и поведение — финальные. Все значения взяты из текущего `ui/static/index.html`; новых цветов и шрифтов нет.

## Общие правила значений (держать во всех элементах)
- Неизвестно — «—», никогда 0. Оценка — «≈». Стоимость по части сессий — «≈ $X» и рядом «у N из M» (план T11: «≥» не используется).
- Время — **местное** для браузера, без пометки; UTC — в `title`. Сегодня — `14:22`, раньше — `30.09 14:22`.
- Длительности: `43 м`, `2 ч 41 м`; открытая больше суток — `23 ч+`.
- Числа — `font-variant-numeric: tabular-nums`; тысячи через узкий пробел U+202F (`8 127`); деньги `$1.23` (точка), от $100 — целые (`$108`).
- ID сессии — 8 + 4 знака: `01a0f57b…4b74`, моноширинным; по клику копируется полный ID (подпись на 1,6 с меняется на «ID скопирован»).
- Одна мысль — одна строка. Заголовки карточек ≤ 80 знаков, пояснение в одну строку с многоточием, полный текст в `title`.

## Анимация: живой процесс
Двигаются только `transform` и `opacity`. Одна анимация на элемент за раз. Длительности 150 / 400 / 600 / 800 ms, кривая `cubic-bezier(.2, 0, 0, 1)`.

**Пульс (шапка, только «Живые данные»)**: `▁▂▅▃▇▂ ● 1 работает · 34 события/мин` (склонение: событие / события / событий)
- 60 столбиков по 2px с шагом 1px (контейнер 179×16px, `overflow:hidden`): последние 10 минут, столбик = 10 с. Высота 0–16px: `min(16, round(n/12·16))`. Стек по агенту: Claude `--accent`, Codex `--ok`; пустой столбик — 1px `--line`.
- Раз в 5 с справа въезжает новый столбик: массив сдвигается, контейнер анимируется `translateX(3px) → 0`, 400 ms.
- Точка 7×7 `--ok`: при новых событиях кольцо поверх точки `scale 1 → 1.6`, `opacity 1 → 0`, 600 ms (в прототипе — Web Animations API).
- Тишина: нет событий 12 столбиков (2 мин) — все столбики `--line`, точка `--ink-3`, текст «тишина 12 мин» («тишина 10+ мин», если пусто всё окно).
- Клик раскрывает выпадающий список (380px, справа, shadow `0 8px 24px rgba(0,0,0,.14)`): «ИДУТ СЕЙЧАС · N», по каждой сессии — проект, первая реплика в одну строку, «12 событий за минуту», «лента →». Пусто — «Сейчас никто не работает.»
- Данные: `GET /api/pulse` (loopback, раз в 5 с, кэш 5 с) → `{bars:[{t, agent, n}], active:[{sid, project, first, last_at, per_min}]}`. SQL — в ux-спецификации.

**Тихое обновление (обе версии)** — при новом `generated_at` данные подменяются на месте:
- числа KPI и шагов цикла досчитывают от старого к новому за 600 ms (ease-out cubic), ширина не прыгает (`tabular-nums`);
- изменившиеся карточки тем — `box-shadow: inset 3px 0 0 var(--accent)` вспыхивает и гаснет за 1,2 с;
- если число шага цикла выросло — точка 6px `--accent` проходит от предыдущего шага к нему, 800 ms;
- новая запись журнала въезжает сверху, 400 ms;
- открытая лента дописывается снизу (см. выше).

**Ограничения**: `prefers-reduced-motion: reduce` — без движения (столбики обновляются сразу, числа меняются без счёта, вспышек нет); распространить правило `index.html:168` на `animation`. Скрытая вкладка (`document.visibilityState === "hidden"`) не опрашивает `/api/pulse` и `/api/dataset`.

## State Management
```
view: fix | overview | sessions | session | friction | tools | skills   (по умолчанию fix)
sid, days (7), agent (all), proj (all), kind (work | all; work скрывает system)
step: sessions | signals | topics | discussed | applied | checked        (цикл)
open: id раскрытой темы; moreTopics: bool; hidden: [id] (localStorage hottell.hidden)
discuss: {key: 'hero' | <finding id> | 'sess:<id>', agent: codex | claude}
copied: ключ последнего копирования (сброс через 1,6 с)
tl: main | all; titleOpen; openJ (раскрытая запись журнала)
pulse: bars[60], active[]; pulseOpen
refresh: idle | busy | same | fail
```
Данные: `/api/dataset`, `/api/sessions/{id}`, `/api/pulse`, `/api/status`, `/api/coach/journal`.

**Тип сессии** (план T2; в прототипе вычисляется в интерфейсе, в продукте — `Session.kind` из `live.py`):
- `system` — сырая первая реплика начинается с `# Overview Generate N to M hyperpersonalized suggestions`, `You are an expert at upholding safety and compliance standards for Codex ambient suggestions` или `## Memory Writing Agent`, либо cwd в `~/.codex/memories`;
- `automation` — первая реплика начинается с `<heartbeat>`;
- `user` — всё остальное.

**Scope находки** (план T12; в прототипе: `kind=diagnostic && source=detector` → `collection`): `collection` — в «Здоровье сбора данных», `work` — в «Темы».

Пустой/отсутствующий проект показывается как «без проекта».

**База подсчётов.** Все числа страницы считаются по сессиям выборки (`S`: фильтры периода, агента, проекта и «Без служебных»). «Ваше время» и «Агент работал» исключают `automation` и называют её подписью; «Ваши сессии» — только `kind=user`.

**Тема** — как в системе (`prefers-color-scheme`), как в нынешнем `index.html`; параметр `theme` прототипа по умолчанию `system`.

**Узкий экран** прототип не показывает. В продукте сохранить адаптивные правила `index.html:162–167`; на 390px у страницы нет горизонтальной прокрутки, широкие таблицы прокручиваются внутри своих панелей.
