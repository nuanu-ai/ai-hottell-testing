# AI Hottell — установка для тестирования

Актуальный клиент **v0.3.6**, macOS Apple Silicon и Intel. Источник:
[`nuanu-ai/ai-hottell`, `camp`, `76da83c`](https://github.com/nuanu-ai/ai-hottell/commit/76da83c871245b6497c9203f765050cb24d21e4b).
Дата обновления комплекта: 7 октября 2026. Точные данные переноса — [SOURCE.json](../SOURCE.json).

## Установка

Go, Docker и GitHub-авторизация для готового клиента не нужны.

1. Откройте сервер Hottell, на котором у вас есть учётная запись вашей команды. При необходимости
   получите приглашение у владельца сервера.
2. На странице «Подключение» выпустите личный MCP-ключ и добавьте сервер `hottell`
   в Claude Code или Codex точно по инструкции этой страницы. Ключ хранится
   локально в конфиге агента; не отправляйте его в чат, Git или отчёты.
3. Установите закреплённую версию клиента:

```sh
curl -fsSL https://github.com/nuanu-ai/ai-hottell-testing/releases/download/v0.3.6/install.sh -o /tmp/hottell-install.sh
sh /tmp/hottell-install.sh
```

Скрипт выбирает архитектуру Mac, сверяет SHA256 и запускает `hottell install`.
Если удалённый MCP `hottell` ещё не настроен, установка останавливается.
Если обнаружены старые чужие хуки, установка также останавливается до правок:
сначала изучите её вывод. Не добавляйте `--replace-foreign-hooks` вслепую.
4. Выполните оставшиеся шаги из вывода установщика: доверие хукам в Codex и
   перезапуск открытых сессий агентов, если он их требует.
5. Проверьте состояние:

```sh
~/.local/bin/hottell version
~/.local/bin/hottell status --json
```

Ожидаемая версия — `0.3.6`. Проведите короткую новую сессию агента и проверьте,
что она появилась в аналитике сервера. Успешное скачивание и установка сами
по себе не подтверждают поступление телеметрии.

## Что устанавливается и куда идут данные

Клиент устанавливает свои хуки и нативный OTel Claude Code/Codex, фоновый
процесс launchd, локальный MCP `hottell-local`, skills `hottell-coach` и
`session-retro`. Данные отправляются на сервер из настроенного MCP `hottell`;
проверьте адрес и раздел «Что отправлять» перед запуском рабочих сессий.
Сервер может получать промпты, содержимое инструментов и транскрипты согласно
его настройкам. Локальный MCP читает сессии на Mac для работы skills.

Это актуальный серверный клиент. Старый отдельный дашборд на 8800/8801 и путь
через `cd hottell && go build` относятся к предыдущей версии и здесь не используются.
Уже запущенные на вашем Mac старые приложения от обновления репозитория не меняются.

## Бэкап и откат

До установки клиент сохраняет `~/.claude/settings.json`,
`~/.codex/config.toml` и `~/.codex/hooks.json`. Каталог бэкапов:
`~/Library/Application Support/hottell/backup/`; имя набора и команда отката выводятся при установке.

```sh
~/.local/bin/hottell restore --list
~/.local/bin/hottell restore <имя-набора>
```

Перед откатом клиент проверяет целостность всего набора бэкапа. Повреждённый
или неполный набор отклоняется до остановки службы и изменения конфигов.
Restore работает без сети и останавливает фоновый процесс до восстановления;
перед откатом сохраняет текущее состояние. Конфиги-симлинки пропускаются с ошибкой,
чтобы не затереть их цели. Перезапустите агентов после отката. Изменения конфигов,
сделанные позднее выбранного бэкапа, заменяются его состоянием. Старые бэкапы
прототипа из `~/.config/hottell-backups/` имеют другой формат и этой командой не читаются.

Удаление установленного клиента — `~/.local/bin/hottell uninstall`.
`restore` возвращает эти три файла к выбранному состоянию. Файл
`~/.claude.json` не входит в бэкап: Claude Code постоянно меняет в нём
собственное состояние. После `restore` запись `hottell-local` в нём остаётся;
`uninstall` удаляет её. Удалённый MCP `hottell` остаётся после обеих команд.
Установленные skills также остаются после `restore`; `uninstall` удаляет
неизменённые skills, которые установил клиент. Эти команды не удаляют данные,
уже отправленные на сервер.

## Из исходников

В репозитории есть исходники клиента и сервера без личных сессий и секретов. Нужен Go 1.27.1:

```sh
git clone https://github.com/nuanu-ai/ai-hottell-testing.git
cd ai-hottell-testing
mkdir -p bin
go build -ldflags '-X main.version=0.3.6' -o bin/hottell ./cmd/hottell
./bin/hottell install
```

Самостоятельный сервер и веб-интерфейс разворачиваются из этого же публичного
репозитория: [инструкция](../README.md).
